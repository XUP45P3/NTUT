## 檔案規範

### 命名規則

| 類型 | 位置 | 命名格式 | 範例 |
| --- | --- | --- | --- |
| 課程總覽 | 根目錄 | `課程名稱.md` | `行銷學.md` |
| 課堂筆記 | `課程名稱/` 資料夾 | `YYYY-MM-DD.md` | `行銷學/2026-09-09.md` |

**為什麼課堂筆記要用 `YYYY-MM-DD`：**
檔案總管與 Git 都是按「字串」排序，不是按日期理解。只有由大到小（年 → 月 → 日）並補滿位數的格式，字串排序結果才會剛好等於時間順序。
若寫成 `9-9.md`、`0909.md`，到了 10 月就會出現 `10-16` 排在 `9-9` 前面的錯亂。

## 新增一門課程的步驟

1. 依上方範本，在根目錄建立 `課程名稱.md`
2. 填入課程資訊、期限與上課規則
3. 回到本檔案，於「課程清單」表格新增一列
4. 若該課程有明確截止日，一併加入「近期重要期限」清單
5. 有課堂筆記時，再建立 `課程名稱/` 資料夾，並以 `YYYY-MM-DD.md` 存放

> 步驟 3、4 容易漏掉。README 一旦與實際檔案脫節，索引就失去意義，建檔後請順手更新。
