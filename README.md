## 撰寫規範

### 命名規則

| 類型 | 位置 | 命名格式 | 範例 |
| --- | --- | --- | --- |
| 課程總覽 | 根目錄 | `課程名稱.md` | `行銷學.md` |
| 課程資料夾 | 根目錄 | `課程名稱/` | `資料庫管理/` |
| 課堂筆記 | 課程資料夾內 | `YYYY-MM-DD.md` | `行銷學/2026-09-08.md` |

**為什麼課堂筆記要用 `YYYY-MM-DD`：**
檔案總管與 Git 都是按「字串」排序，不是按日期理解。只有由大到小（年 → 月 → 日）並補滿位數的格式，字串排序結果才會剛好等於時間順序。
若寫成 `9-9.md`、`0909.md`，到了 10 月就會出現 `10-16` 排在 `9-9` 前面的錯亂。

### 課程總覽格式

區塊依下表順序排列，各區塊之間以 `---` 分隔。**有資訊才寫，沒有就整個區塊省略。**
最完整的範例可參考 [化學（一）.md](化學（一）.md)。

| 順序 | 區塊 | 格式 | 內容 |
| --- | --- | --- | --- |
| 1 | 課程資訊 | 表格（項目、內容） | 依序為授課教師、信箱、電話、辦公室、上課地點、上課時間，沒有的欄位省略 |
| 2 | 重要日程 | 表格（日期、週次、項目、備註） | 考試、報告、繳交期限、一定要到的課 |
| 3 | 評分方式 | 表格（項目、佔比） | 表格下方可加補充說明或子區塊 |
| 4 | 上課規則 | 條列 | 點名、請假、調課、注意事項 |
| 5 | 課程進度 | 表格（週次、日期、內容、備註） | 每週上課內容，**週次與日期缺一不可**；老師沒有提供每週進度就省略 |
| 6 | 教科書 | 表格（項目、內容） | 書名、作者、出版 |

**區塊排序的理由：** 越常查的放越前面。「在哪上課、什麼時候考」每週都會查；評分方式與上課規則多半開學看一次，之後偶爾確認；課程進度篇幅最長，放在後面才不會把重要資訊擠到下方。

### 書寫細節

| 項目 | 規則 | 範例 |
| --- | --- | --- |
| 日期 | `MM/DD`，補零 | `09/08`、`10/16` |
| 一週多次上課 | 日期以 `、` 分隔 | `09/09、09/10` |
| 時間 | `HH:MM–HH:MM`，連接號前後不留空格 | `13:10–15:00` |
| 上課時間 | 星期 + 節次 + 時間 | `星期二 5、6 節（13:10–15:00）` |
| 週次 | 表格中只寫數字 | `5` |
| 括號 | 中文內容使用全形 `（）` | `陳秀慧（分子）` |

## 更新資料的步驟

1. **先改課程總覽檔**，它是資料的來源
2. 若改到授課教師、上課時間或地點 → 同步更新本檔案的「課程清單」
3. 若改到重要日程 → 同步更新本檔案的「重要日程總覽」
4. 課堂筆記存放在 `課程名稱/YYYY-MM-DD.md`；建立課程資料夾後，記得在「課程清單」補上連結

> 步驟 2、3 最容易漏掉。README 一旦與課程檔脫節，索引就失去意義。
